Overview

I was contracted by Apple to work on this image-validation backend system. I built an `apple-backend` FastAPI service for validating image records against configurable rule contracts and persisting validation outcomes to PostgreSQL. My backend exposes versioned REST endpoints, routes image-validation requests through a dedicated business-logic layer, and serializes structured response payloads for downstream review or ingestion workflows.

Introduction

I treated large-scale image validation as a backend systems problem: before records can enter a training, annotation, or review workflow, they need deterministic validation gates. I formalized that validation step as an API-backed quality-control layer where clients submit image metadata and candidate validation values, my backend evaluates those values against threshold rules, and the result is recorded with status, rule outputs, failure reasons, model/upload context, and timestamps.

Methods

I separated transport, routing, validation logic, configuration, and persistence. The FastAPI application handles startup/shutdown lifecycle events, initializes an asynchronous PostgreSQL connection pool, and fans requests into versioned route handlers. The core validation endpoint receives an `ImageValidationRequest`, applies comparison operators such as greater-than, greater-than-or-equal, less-than, less-than-or-equal, and equality through `evaluate_contracts()`, then maps each request to `APPROVED`, `REJECTED`, or `RETRY` based on passed rules and exception handling.

What Was Built

I built health/time/hello service routes, a `/api/v1/validation/validate-image` validation flow, Pydantic-based application settings, async database utility functions, and a `ValidatedImages` PostgreSQL schema for durable storage. My response builder returns typed `ImageValidationResponse` objects containing fields such as status, collection ID, rules passed, rules failed, raw outputs, image ID, model/upload metadata, and validation timestamp.

Conclusion

My final service turns image quality control into a modular backend system instead of an ad hoc notebook or script. By combining FastAPI routing, Pydantic configuration, rule-contract evaluation, async PostgreSQL writes, and explicit lifecycle management, I created an auditable validation layer that can sit between image upload, model output generation, and human-in-the-loop review.
