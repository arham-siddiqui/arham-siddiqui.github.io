Overview

I was contracted by Google DeepMind to develop this software for AI trust and autonomy research. I developed a trust-gated autonomy framework for assistive AI, demonstrated through a Google Gemini and LangChain-powered Calendar agent. My system pairs Google Calendar API tool calling with a Beta-Binomial trust estimator and a Hybrid LinUCB contextual bandit, allowing agent autonomy to adapt from observed user reliance, compliance, overrides, edits, and uncertainty rather than remaining fixed.

Introduction

I approached LLM-agent autonomy as a systems problem: once an agent moves from passive recommendation into tool-mediated execution, it has to decide when to call tools, when to propose alternatives, and when to require explicit confirmation. I used calendar automation as the testbed because scheduling exposes structured state, temporal constraints, user-specific preferences, and measurable correction signals after each interaction sequence.

Methods

I separated capability from control. The capability layer uses Google Gemini, LangChain, and Google Calendar API tools to parse natural-language scheduling requests, inspect calendar state, infer intent, find free slots, create/edit/delete events, and generate conflict-aware alternatives. The control layer models trust with a Beta-Binomial Bayesian update and adjusts autonomy using a Hybrid LinUCB contextual bandit over actions {-2, -1, 0, +1, +2}, constrained to valid movement along a six-level autonomy ladder.

What Was Built

I built LangChain tool wrappers for Google Calendar primitives, Gemini-based intent reasoning, free-slot discovery, event creation/edit/deletion, LLM-generated scheduling suggestions, conflict-aware rescheduling, persona-conditioned proposal behavior, and a modular autonomy controller. My adaptive layer consumes interaction outcomes, user overrides, edit magnitudes, reliance/compliance signals, and posterior trust uncertainty to select the next autonomy-level transition.

Conclusion

My conclusion was that assistive AI should behave like a calibrated collaborator: initiative should expand when the user repeatedly accepts and relies on the agent, and contract when corrections, overrides, or uncertainty indicate discomfort. My prototype demonstrates the calendar-agent side of the system and outlines how trust estimation and contextual-bandit control can generalize to other domains such as email, task planning, and travel booking.
